# 介绍：IRify



多语言通用代码审计产品：**IRify** 正式发布。

本产品以代码查询规则 `SyntaxFlow` 和多语言通用中间表示 `YakSSA` 为核心，支持**代码审计**、**规则管理**、**代码扫描**、**漏洞风险信息处理**等功能。已支持 Yaklang \ Java \ PHP \ Golang 。

欢迎访问产品主页: https://ssa.to/ 或 https://www.yaklang.com/irify  下载使用。



# 编译项目

SyntaxFlow代码审计与代码扫描前都需要先进行项目编译。

## 手动编译

### 项目管理

点击左上角项目管理

> 可见图中红色方框圈起的选项

编译项目的选项如下：必选项为项目路径

在**项目管理**页面中，可以看到已编译项目列表，将会显示已编译项目的名称、路径、编译时间和相关操作。可以进行该项目的打开、扫描以及项目删除等操作

# 代码扫描

## 开始扫描

首页和左上角均可进入代码扫描页面

![示意图 @@@@ 图片为代码审计系统的界面截图。上方有多个功能图标，其中一个被红框突出显示。下方有“代码审计”“代码扫描”“规则管理”三大板块，分别介绍相应功能，并有“开始审计”“开始扫描”“查看规则”操作按钮，展示了系统的主要功能和操作入口。](/media/articles/ef4226f7a90d7f86.webp)

导入新项目或选择已有项目后，再勾选左边规则，即可开始代码扫描。

![示意图 @@@@ 图片展示了一个代码检测相关的操作界面。左侧有“扫描规则”区域，橙色方块列出多种规则；中间为“已选规则”列表；右侧“规则执行”区显示项目路径，并有“开始翻译”按钮。上下文可能与代码扫描规则设置及执行相关。](/media/articles/80900d09b53f8505.webp)



## 扫描信息

扫描过程中，可以看到已选规则、风险统计、扫描进度等信息。

风险与漏洞列表中可以进行删除、在代码审计中打开、误报上传等操作。

![示意图 @@@@ 图片展示的是一个代码检测相关界面。左侧显示“已选规则104/158”，右侧“规则执行”部分显示进度为24%，下方有“漏洞与误报”等板块，展示了规则执行的相关信息，如规则名称、执行进度、状态等，与代码检测操作的上下文相关。](/media/articles/cccd892c4c84cd97.webp)

扫描结果可以从左上角进入数据库查看

![示意图 @@@@ 图片是某系统界面截图，展示了审计漏洞相关内容列表。界面上方工具栏处有两个红框标注的功能按钮，其中一个是齿轮状的“设置”按钮。上下文可能是在介绍该系统中审计漏洞相关功能及操作。](/media/articles/91b31ae6ed7f9092.webp)

# 代码审计

## 打开已编译项目

打开已编译的项目，将会跳转至代码审计页面。

可以检查文件内容，但这些已经编译的项目文件内容是只读的。

![代码/伪代码 @@@@ 图片展示了一个代码编辑界面，左侧是文件目录结构，右侧是代码编辑区域，其中有不同颜色高亮显示的代码内容。但由于缺乏具体上下文，无法明确其与标题及上下文的关系。](/media/articles/c61b9af967271b12.webp)



## 输入代码审计规则 

在左侧侧边栏中可以看到代码审计选项， 点开以后可以发现编写审计规则的窗口：

![示意图 @@@@ 图片展示了一个代码编辑界面，左侧有文件目录结构，中间是代码编辑区域，显示“TaskTimeoutJobHandler.java”的代码内容。左侧工具栏有一图标被红色框标注，并有红色箭头指向下方的“定时任务”区域，下方弹出框展示了定时任务配置示例代码，与代码编辑内容相关。](/media/articles/22d2b7b7c9b7ab6f.webp)

## 结果信息

每一次查询都会得到一个变量列表，如同上文所示，在SyntaxFlow规则中定名的变量都会在结果中列出。

点开变量名将会展示该变量内保存的所有结果，点击查看其中的某一项结果，YakRunner将会展开以下结构，编辑器将会跳转到该结果对应的源码位置：

![示意图 @@@@ 展示了代码审计工具的操作界面。画面中红框突出显示了“数据”按钮、“发起代码自动扫描”弹窗以及审计结果列表。箭头指向了从点击“数据”到发起扫描及显示结果的流程，与代码审计的上下文内容相关。](/media/articles/1cc6b9d71312f7d4.webp)
